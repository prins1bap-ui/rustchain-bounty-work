## Suggested excerpt

Legend of Elya targets the Nintendo 64 with a compact transformer implementation and a documented libdragon workflow. This walkthrough follows the public source, explains the current model/build path, and shows how the repository's ares rate-probe script is intended to be reproduced without pretending that unperformed physical-hardware benchmarks happened.
