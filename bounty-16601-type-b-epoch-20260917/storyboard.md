## Capture QA

- Capture only public repository material.
- Keep file paths visible when a technical claim is on screen.
- Do not show wallet balances, private keys, tokens, credentials, or account data.
- Do not imply that conceptual graphics are live measurements.
- If repository text has changed before production, use the current source and adjust narration rather than preserving a stale claim.
