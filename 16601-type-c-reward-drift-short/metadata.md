## Description

A live RustChain bounty currently shows one RTC reward in its title and another in its body. This Short demonstrates the read-only Bounty Spec Linter + Reward Drift Detector built by `@prins1bap-ui` to surface that class of inconsistency for human review.

Sources and runnable code are public:
- https://github.com/Scottcjn/rustchain-bounties/issues/13226
- https://github.com/prins1bap-ui/rustchain-bounty-work/tree/main/402-bounty-spec-linter

No payout or acceptance is inferred from the conflicting figures shown in the example.
