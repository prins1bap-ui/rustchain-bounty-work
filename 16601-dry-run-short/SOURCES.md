## Claim discipline

- This package does **not** claim that a live miner run was executed for this package.
- It does **not** invent terminal output, benchmark results, wallet balances, detected hardware, fingerprint values, successful submissions, or network responses.
- The visual plan explicitly instructs an editor to capture authentic output only if a real test environment is available; otherwise it stops at the documented command and labels the next step as user-specific inspection.
