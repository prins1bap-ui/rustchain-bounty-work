# Industrial Technical Documentation Revision Proof

This portfolio proof demonstrates a controlled revision workflow for industrial instruction manuals and operational standards. It is an engineering/documentation sample, not a claim of prior paid client work.

## Revision approach

1. Treat the client's source guide, verified dimensions, specifications, photographs, illustrations, and revision brief as authoritative.
2. Build a revision matrix before editing so every requested change is traceable to a source.
3. Separate factual changes from layout/clarity changes.
4. Never invent dimensions, capacities, classifications, tolerances, handling requirements, or safety claims.
5. Flag conflicts or missing source information instead of resolving them by assumption.
6. Preserve revision history and produce both editable source and print-ready output.

## Deliverable structure

- Editable InDesign source (`.indd` or `.idml`)
- Print-ready PDF
- Revision matrix showing source, requested change, implemented change, and status
- Technical consistency checklist
- Exception list for unresolved or contradictory inputs

## Quality controls

- Units and dimension formatting checked consistently
- Product/type identifiers cross-checked across tables, callouts, and captions
- Figures and photos linked to the correct specification entries
- Safety or handling language preserved unless the client explicitly supplies revised wording
- No unsupported engineering conclusions
- All outstanding ambiguities listed before final sign-off

## Tooling

The workflow can use Adobe InDesign for editable source and print output, with structured revision tracking outside the layout file. This keeps the document professionally editable while preserving an auditable record of factual changes.
