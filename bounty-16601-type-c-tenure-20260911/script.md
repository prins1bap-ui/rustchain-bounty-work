# Script — “Your Old Computer Gets a Loyalty Bonus”

Target runtime: 48–55 seconds at 135–150 wpm.

**0–4s — Hook**  
What if your old computer got *more* valuable to a network the longer it stayed online?

**4–13s**  
RustChain calls this a tenure-grown multiplier. Hardware starts with a base Proof-of-Antiquity weight tied to its class and age.

**13–25s**  
Then RIP-200 adds five percent for each year that hardware has been mining on the network, capped at fifty percent after ten years.

**25–37s**  
So a machine does not lose its place just because newer hardware arrives. Its network tenure compounds on top of its base multiplier.

**37–47s**  
The idea is simple: preserve useful old hardware, reward longevity, and make staying active worth something.

**47–54s — CTA**  
Want to see whether your machine qualifies? Start with `pip install clawrtc` and read the RustChain mining docs.

## On-screen disclosure

“Multiplier examples are protocol-defined weights, not a promise of financial return.”
