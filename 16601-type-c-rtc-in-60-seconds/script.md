# RTC in 60 Seconds — Type C Short

**Target:** 45–55 seconds, vertical short

Old computers usually lose value because newer hardware is faster. RustChain deliberately tries something different: it rewards verified physical hardware partly according to its antiquity.

The network calls this Proof of Antiquity. A miner identifies its machine and submits hardware-fingerprint evidence so the network can distinguish physical machines from virtualized or emulated environments.

That means the interesting question is not simply, “How fast is this CPU?” It is also, “What machine is actually doing the work?”

RustChain's public project documents describe support for a wide range of architectures, from PowerPC and SPARC to modern x86 and ARM.

Want to inspect it instead of taking a short video's word for it? Start with the public RustChain repository and its Proof-of-Antiquity documentation.
