# Storyboard — RTC in 60 Seconds

Format: 9:16 vertical, 1080×1920. No third-party footage required.

| Time | Visual | On-screen text |
|---|---|---|
| 0:00–0:06 | Split screen: generic old beige computer silhouette vs modern desktop silhouette. Simple generated/vector shapes only. | `What if OLD hardware had an advantage?` |
| 0:06–0:14 | RustChain title card, then animated scale with “speed” on one side and “hardware antiquity” on the other. | `Proof of Antiquity` |
| 0:14–0:25 | Flow diagram: Physical machine → fingerprint evidence → network verification. | `What machine is actually doing the work?` |
| 0:25–0:34 | VM/emulator window icon fades behind a physical-chip icon. Avoid claiming perfect detection. | `Physical-hardware verification matters` |
| 0:34–0:44 | Architecture names animate in: PowerPC, SPARC, x86, ARM. | `Multiple hardware generations` |
| 0:44–0:52 | GitHub repository mock terminal/card. | `Inspect the source yourself` |
| 0:52–0:56 | End card. | `github.com/Scottcjn/Rustchain` |

## Capture notes

Use generated geometric assets and text, not copyrighted hardware photos. Keep every shot readable on a phone. Do not show token prices, ROI, guaranteed earnings, or fabricated miner output. The short intentionally explains the concept without making quantitative reward claims that could drift as the implementation changes.
